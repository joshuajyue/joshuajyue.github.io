# Joshua Yue's portfolio

Source for [joshuajyue.github.io](https://joshuajyue.github.io), a static engineering portfolio highlighting
Joshua's Microsoft software engineering internship, resulting .NET contributions, and selected projects.

The site uses a monochrome editorial layout with an accessible tabbed timeline, filterable project grid,
deep-linkable project detail dialogs, light/dark themes, and reduced-motion support.
